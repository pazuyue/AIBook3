# 《三月女神今天也只是普通学生》幕后推手设定

> **2026-09-28 用户定稿：复活始主与双弃子布局。** 本文件定稿组织目标、行动逻辑与认知边界；始主、混合力量、封印与回收机制以《世界观设定》为准。旧激进救世目标、陆沉求死所以无法利用、第一卷组织完全不露面的口径退出执行。

## 一、唯一终极目标

组织唯一的终极目标是**复活始主**——当年与三月女神同归于尽、残存力量被三月封印的对象。

打开封印只是宏大计划的一步，不等于始主已经复活。试探、诱使哥伦比娅介入、接触并拉拢她，都是手段。不再采用“为重新锁死反面、挽救世界而逼醒三月继承人”的激进救世动机。

组织名称、成员结构、复活的完整条件与全套步骤尚未定稿，不借本轮同步补完。

## 三、三年前的发现与认知缺口

三年前第三区冰封反面事件中，组织发现了自己所称的“始主之力”，以及与这股力量有关的女孩——哥伦比娅。围绕她的计划由此启动，不再写成第一卷偶然发现目标。

**特征是真的，归属解释错了。** 三月封印内，两股力量长期对立又交缠混合，后世无法准确区分；组织将冰封与哥伦比娅的响应纳入始主一侧的解释。

组织不知道她实际上是三月女神的外来继承人。“始主代理人”是第一卷事件后形成的组织判断，不是作者定性；不追加始主血统、双源继承或人格控制。

三年间的跟踪方式、情报渠道及当前行动窗口依据待定。发现相关女孩不等于掌握完整本质、能力上限与全部生活记录。

## 四、第一卷：主动浮出水面的一次试探

### 双弃子布局

林昭身死当年的灾难与死后亵渎来自同一施害链。组织让出直接责任者，配合陆沉复仇机会的形成，借此诱使哥伦比娅介入。

**陆沉与复仇对象都可以是弃子。**他们的爱恨、求死、野心与生死不是组织要满足的目标，只是推动所需行动的条件。

- 不必让陆沉真信林昭能复活；复仇仍能推动他行动，识破诱饵或接受死亡不代表免疫利用。
- 陆沉杀死仇敌可以是真实复仇，此人死亡也可以在组织允许的成本内。
- 组织已定的配合方式，是在陆沉能够接触的内部开放资料中，偶尔、有控制地泄露当年灾难扩大及负责人责任的真实信息，并放任他核查后继续合作。不是伪造罪证或直接递交复仇结论，也不默认另有撤援、替陆沉布置机关等安排。
- 陆沉仍能留下错配数据、记录和警告；作用真实，但不预设必须导致组织第一卷整体失败。

### 明面负责人、虚假复活与资料泄露（2026-09-28 补定）

**负责人职责**：此人当年主持对旧都既有封印的非法干预，造成灾难扩大，使林昭陷入牺牲处境；现在又负责组织本次封印解除，是行动台前的负责人。其现场参与来自既定职责和任务，不依赖额外的研究成果验收诱饵。

**拉拢陆沉**：他以林昭遗体和“可以复活她”的虚假许诺换取合作。遗体是真实的，复活许诺是假的；其中封印、融合等技术可以有效，但不能因此写成真能复活林昭。遗体在这段合作中的功能是情感筹码，不强制给此人新增十二年遗体首席研究者身份；具体回收、保存、研究者仍未定。

**组织的公开资料**：只指组织内部向陆沉开放、允许其接触的材料，不是社会公共档案，也不表示他获得组织全部权限。组织在他调查时偶尔泄露真实信息，使当年灾难扩大与眼前负责人的责任逐渐能够对应。组织选择可见条件，陆沉仍须自行核查，不能只凭编号定罪。

**合作转为复仇**：负责人拉拢 → 陆沉合作并调查 → 组织有限泄露真实责任线索 → 陆沉确认血债但不立即翻脸 → 继续参与开封准备，借负责人原定要进入的现场布置同归局。组织允许利用双方的合作与决裂来促使哥伦比娅介入。

不采用“活体融合成果只能现场验收，负责人为独占成果赴约”的设计，不另造宝物、研究奖励或只有本人能通过的权限。现场参与理由已定；他为何未及时识破复仇、如何被留在现场及逃生条件仍待规划。

### 已确认结果（本卷止于线索与关联核实）

1. 陆沉借负责人既定开封行动，在浅层反面布置复仇同归局；局部撕封与救援后果真实，人物节点归《反派导师设定》。
2. 哥伦比娅介入，但**第一卷不真正触动或打开上古封印，不启动权柄碎片回收**。导师战后刻意留下、真实能救陆沉、最后获得线索的安排不变。
3. 组织三年前已发现冰封力量及相关女孩；这次在新的事件条件下核实她本人力量与封印的关联，不只是重复旧事故推断。观测与比对的具体证据、渠道待定，不靠留场本身证明关联，也不默认监听私谈。
4. 组织将关联核实解释为“始主代理人”的证据，继续主动露出并在后续接触拉拢。它确认的是关联，不是真实三月继承身份。

**女主留场的两项主线功能：获得线索／组织核实封印关联。**挽救陆沉是人物选择，不被这两项功能取消。

真正的上古开封、回收启动及其引发的封印新松动、全面怪异加速后移，具体卷次待定。“潘多拉魔盒”不再作为第一卷已经开启的世界状态，亦不是新增实体道具。组织可取得试探成果，但尚未取得女主真正开封的结果。

## 五、已有载体与最后警告

旧时代笔记、遗体与日志交付、“复活计划”技术合作、自我实验和数据回流保留；不把已写正文登记为已揭晓新真相。

明面负责人对陆沉许诺的是虚假的“复活林昭”，组织真正要复活的是始主，不能混成一个已公开计划。第19章容器场不必提前揭出组织全貌、始主或负责人责任；内部资料泄露、陆沉确认血债及负责人入场的具体时点待新分场。

导师战后，陆沉强制传送方导师与四人组出反面。哥伦比娅刻意留下并提出真实可行的挽救；他由此确认她不凡，交出部分发现。允许的警告核心是三年前冰封、相关女孩、围绕她的行动以及对方称谓“始主”。陆沉不因此全知，不解释完整混合机制与复活条件。

## 七、执行边界

1. 私人复仇不是组织自身目的；组织也不是全知者。
2. 陆沉有主动选择，也能被利用；复仇成功与组织阶段成功可以并存。
3. 伤情与危害不以“全在计划内”抵销，学生救援与导师保护必须有效。
4. 力量特征识别与身份解释分开；“始主代理人”只能作为组织认知。
5. 不把女主写成始主容器，不自行补齐始主与旧“上古黑暗”的全部终局映射。
