## 一、变更摘要

### 1. 方导师：核心「压线」→「界限」（旧招式全部废止）

- 核心名「压线」→「界限」。
- 硬边界：**「她能移动界限，不能制造界限」**（与陆沉"能移动一拍，不能制造一拍"对仗）。
- 战斗载体：露指拳套 + 七枚钢桩（界桩）；桩阵=她的区域。
- 能力定义：感知目标"已存在的界限"（出力安全上限、核心负荷极限、身体耐受线、状态临界点）并前移/后移。
- 阶段名替换：
  - 界痕显相期 → **见限显相期**
  - 压阵深显期 → **桩阵深显期**（第一卷主状态）
  - 封界解放期 → **有量解放期**
- 旧招式 → 新五招映射表：

| 旧招式（废止） | 新招式 |
|---|---|
| 踏界、界痕击、偏界压 | **挪限**（调低对方出力界限：全力者自碎） |
| 界钉、横封、封壁、锁口、四锁桩、界投 | **量场·桩阵**（七枚钢桩成阵，阵内免接触调界） |
| 归线护、逐界 | **借限**（上调队友界限）或**挪限**，按语境二选一 |
| 终封式 | **钉限**（钉死状态界限：不许攀升、变身、升华、再生加速） |
| 界场、道封、困界、界裂洞见 | **量场**（真名解放形态：区域内界限由她宣告） |
| （新增技） | **诊度**：接触/近距观察读取界限；读状态不读心；对体系外存在/三月权柄"诊不出线" |

- 真名解放五件套（登记用）：
  - 核心表名：界限
  - 完整真名：**界限·万物有量**
  - 解放语：`【分寸之内，我说了算——真名解放，界限·万物有量。】`
  - 动词质变：从"调"（接触/桩阵后移动单条界限）到"定"（区域内一切已存在的界限由她直接宣告）
  - 形态变化：七枚钢桩离手钉入虚空七方，灰线从大地长出铺满区域，阵内目标体表浮现淡灰刻度
  - 可见代价：解放期间她的身体成为区域内所有界限的总容器代偿；解放后界限视觉熄灭一段时间+全身刻度状瘀痕数日不退
- 其他关键口径：
  - 借限=上调自己/队友界限，**战后翻倍清算**（借债制）
  - 数量上限：常态三条、桩阵七条；桩被拔一根调节少一路
  - 调节幅度与目标强度成反比
  - 她对主角哥伦比娅用诊度**诊不出线**
  - 卷末对决三幕：**义愤（导师守界）→ 挽回（迟到的在场）→ 成全（送葬人挪线）**

### 2. 陆沉：核心「催律」规则不变，仅加战斗载体

- 核心规则一字不动：「他能移动一拍，不能制造一拍」；读得出节拍，读不出心。
- 战斗载体（新增）：右手教习细剑 + 左腕刻度盘；移拍经兵刃接触传递（**触剑移拍**）；听拍=**耳代目**（看过对方完整出手一次即可拨）；落刻=剑尖留痕（辅助，不作战斗前置）。
- 反制（新增）：没有固定节奏的爆发型对手（如白砚河）克他。
- 正文用语口径：写节拍效果统一用「**半秒**」，不用「不足一拍」；「不足一拍」仅作设定层硬边界保留。
- 崩解帧（死亡瞬间口径）：无名字的质变"听见的都归我"，只存在一拍，不写解放语、不写真名；是否点破"解放即崩解"留正文裁量。
- 对封印结构的移拍质变 = 融合异化带来的**伪质变**，不是真名解放。
