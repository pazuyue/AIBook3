# 第一卷故事链路：小故事单元 → 一卷大故事

> 整理日期：2026-10-08。基于已写第1-19章正文。

## 二、逐单元拆解

### U1 冰封的反面（第1章）— 事件单元：降临
- **小故事**：穿越者睁眼即绝境，濒死瞬间"世界静止"，一支处置队走进一片不该存在的霜。
- **单元闭环**：灾难解决（怪物全灭），幸存者被按救助流程带走。
- **抛出的钩**：①她是谁（三轮月亮/银发）②冰封真相（三零档案）③幕后"十七号信号中断"④方导师的"待核"。
- **大故事功能**：全书总谜题的"案发现场"。所有后续悬疑线的原点。

### U2 医院与新家（第2-3章）— 日常单元：被捡回去
- **小故事**：一个查无此人的孤儿，被一个迟钝而温柔的医官捡回家。她决定把冰封之夜咽进肚子里。
- **单元闭环**：收养成立，白灯亮在门口——"家"第一次成立。
- **抛出的钩**：水杯静止（F007）、厚瓷杯替换、名字的含义、月相仪的存在。
- **大故事功能**：确立"守护日常"动机的第一块基石；藏身份的自觉起点。

### U3 处置队日常·葬礼·复仇夜（第4-6章）— 情感单元：失去与选择 ★前史核心
- **小故事**：闯入大人日常的小孩刚把日子过暖，日子就被撕碎。葬礼当夜她走向残体，抬手冻结了整条街——却在最后一秒松开了手指。
- **单元闭环**：复仇没有发生。"毁掉它和让他回来，根本不是同一件事。"她选择留下这双手，回去煮粥。
- **抛出的钩**：发绳+银月扣（F008）、0.7秒记录中断（F009）、"原来我一直收着的是这样的东西"。
- **大故事功能**：全书"不变成怪物"选择的第一次重大演练；发绳成为入学动机的信物；情感断崖为第二卷"空位"埋骨。

### U4 入学与307（第7-9章）— 日常单元：第二盏灯
- **小故事**：S级新生检测出一块仪器无法命名的白屏，搬进307，第一天晚上头发炸了。室友说："不要一个人硬撑。"
- **单元闭环**：307共同体成立，宿舍小灯=白灯接力。
- **抛出的钩**：白屏+S级+无编号白刻（F010）、断线瞳"看不进她"（未入表）、发绳=入学动机（F008回收）。
- **大故事功能**：误判链第一环（零波动→S级）；第二个"家"开始搭建。

### U5 实战测试（第10-11章）— 事件单元：四人初显形
- **小故事**：积分制实战里四个怪胎各显神通；隐藏精英考核砸下来，她坐在原地没躲——一根冰刺解决了60分，也解决了"她到底会不会保护人"的考题。
- **单元闭环**：94:93，一分之差。四人通过测试，银序一班成型。
- **抛出的钩**：竞争种子（F018）、陆沉的记录（F015）、"疑似临显待复测"（F016）、"你的线就不会断"承诺（未入表）。
- **大故事功能**：误判链第二环（白刻→冰霜核心局部外显）；四个人的能力/缺陷第一次成体系展示。

### U6 第一课（第12章）— 喜剧单元：常识崩坏日
- **小故事**：第一堂课她举手问"直接拿不就好了"；走廊上一只手接住了新生最强的拳头——她只是嫌烫。
- **单元闭环**：损耗喜剧闭环（三支铁锈液）；方导师的疑虑从"异常"转向"刚好够用"。
- **抛出的钩**：方导师疑虑发芽、苏弥的观察本、实训预告（旧训楼B区+防护贴片）。
- **大故事功能**：悬疑从仪器层（U4/U5）升级到人脑层——方导师开始用"人"的方式怀疑她。

### U7 账单与无效内卷（第13章）— 日常悬疑单元：异常渗进日常 ★结构枢纽
- **小故事**：S级积分余额7。为了饭钱，她跟着室友去旧楼做巡检兼职，在封印前闻到了三年前那个夜晚的气息——画布上有道裂纹。
- **单元闭环**：她精准地把渗透压了回去，无人看见；但方导师在同一晚开始了实际核查。
- **抛出的钩**：B区封印裂纹（→U9）、方导师"刚好够用"转为核查行动、陆沉的B区兼职提议（是照顾还是引导？）。
- **大故事功能**：三条暗线首次同框（她的秘密/方导师的调查/旧训楼封印）；"日常"与"灾难"开始共用同一扇门。

### U8 组队与暴走（第14-15章）— 事件单元：四人焊死
- **小故事**：苏弥带着数据来组队；三人钻裂缝刷分刷得鸡飞狗跳；另一边，不服气的白砚河把妖血借过了线——一巴掌把他从怪物边缘扇了回来。
- **单元闭环**：四人小队成立；考核成绩公布；下一秒，封印崩了。
- **抛出的钩**：封印崩裂+传送失效（直送U9）、陆沉"我来"的担保、妖血暴走机制。
- **大故事功能**：喜剧节奏顶点=灾难引爆点；四人桌的关系地基在笑声里打完。

### U9 降临与关门（第16-17章）— 高潮单元：英雄与门 ★卷中高潮
- **小故事**：考核场变成屠宰场，学生们各显神通求生；副导师逆着撤离人流走进裂缝，用一只手臂换回一个学生；校长三秒千针、三十秒锁界，一个人走进了门里。
- **单元闭环**：门关了。陆沉成了英雄。门后的庞大轮廓"安静地朝这边望着"——离她三米。
- **抛出的钩**：英雄伤（F030伏笔）、"他没有看到我"、胸口内袋硬而薄的物件（F019）、书签在黑泥里多停了一秒（F020）、封印只张开一线放人（F022）、"他们才是你的战场"（F023）。
- **大故事功能**：战力天花板展示（顺便反衬她的深渊）；陆沉从"温和副导师"翻向"破碎循环"的第一页；她与"同类"的第一次对视。

### U10 余波（第18章）— 收束单元：疑点全部上桌
- **小故事**：方导师冷酷清场，确认封印完整度60%且不可逆减弱；医疗区里换药、递话、还有一只被遗忘四天的蚕蛹。
- **单元闭环**：现场清理完毕，官方口径"原因待查"；所有调查方（方导师/陆沉/苏弥）手里都多了一块拼图。
- **抛出的钩**：60%不可逆（F021）、裂缝位置=冰封中心（F024）、陆沉"月相仪弄短路"的递话、零反应数据。
- **大故事功能**：把U7-U9散落的疑点归拢到三个调查者手中，为U11的刺探与盘问装弹。

### U11 四人桌·刺探与容器（第19章）— 双场单元：明线团圆，暗线合流 ★转向卷末
- **小故事A（明线）**：四天后，食堂四人桌正式成立。蚕蛹恩怨、限量星果、旧训楼八卦——日常在废墟上重新开张。
- **小故事B（暗线）**：办公室盘问，她全部字面真实应答，换来一盒铁盒饼干"归你了"；深夜封样间，一件从第三区回收的无编号容器摆在陆沉面前，他听了七圈，把记录板留在了桌上。
- **单元闭环**：明线团圆（四人桌）；暗线合流（方导师上调监测F026、陆沉决定入局、F019点亮第一层）。
- **抛出的钩**：容器之名（未印）、陆沉的"破碎循环"、灰白纹路蔓延（F030）、"异常画面给我"（F026）、苏弥停在第四颗星的注视。
- **大故事功能**：卷中点。此后日常桌与暗线桌并行，向卷末收束。

## 三、四条贯穿线（小故事串成大故事的"线"）

### 线A·身份悬疑线（她藏得住吗）——大故事的主轴
```
U1冰封(三零档案) → U4白屏白刻(S级误判) → U5冰霜外显(疑似临显待复测)
→ U6-U7刚好够用(方导师实际核查) → U10零反应+位置重合 → U11盘问+监测上调
```
每个单元都让"误判"升一级、让"调查"近一步。收束方向：盘问与边界（节拍Ch9-12）。

### 线B·陆沉/幕后暗线（他在找什么）——大故事的里轴
```
U5记录(三次峰值F015) → U8担保("我来") → U9逆行+英雄伤+样本书签(F019/F020)
→ U10递话(月相仪弄短路) → U11容器入局(破碎循环/记录板空置)
```
与线A在U11首次同框（容器回收地点栏写着"反面"=她出现的地方）。

### 线C·旧训楼封印线（门还撑多久）——大故事的倒计时
```
U7画布裂纹(她感知) → U8崩裂(降临) → U9关门(校长) → U10六十不可逆(F021) → ？
```
封印只会越来越薄。这是悬在所有日常单元头顶的沙漏。

### 线D·家与灯的情感线（她为什么藏）——大故事的心脏
```
U2白灯成立 → U3灯灭+复仇夜选择(不变成怪物) → U4宿舍小灯接力(F006)
→ U8-U9用力量守住了什么 → U11四人桌(新日常成立)
```
"不变强就守不住日常，用错力量就会失去日常"——每个单元都在这两个恐惧之间走钢丝。

## 四、单元咬合机制（单元是怎么"串"起来的）

1. **章尾钩子三级**（文风设定§四.7）：每个单元结尾必抛下一单元的入口——U1抛"她是谁"，U3抛"发绳"，U4抛"白刻"，U7抛"裂纹"，U8抛"崩裂"，U9抛"门后的注视"，U11抛"容器"。
2. **状态交接**：每个单元结束时，人物状态表必有一项永久改变（被收养/祁远之死/白刻入档/积分7/四人小队/陆沉左臂/监测上调），下一单元从新状态开局，不倒退。
3. **日常-异常交替呼吸**：事件单元（U1/U5/U8/U9）之后必跟日常单元（U2/U4/U6/U10）消化冲击，异常强度逐轮抬升：水杯静止→白屏→冰刺→封印崩裂→门后注视。
4. **伏笔跨单元埋收**：短钩当单元收（F013海藻预告→回收），中钩跨3-5单元（F008发绳、F015记录），长钩贯穿全卷（F001三轮月亮、F010白刻、F019-F021陆沉线、F024冰封坐标）。
5. **视角分工**：她的单元走日常与选择，调查者的单元走疑点与拼图（方导师=表侧调查，陆沉=里侧暗线，苏弥=平民推理），幕后只给一句远雷（U1/U11）。

## 五、卷末段单元划分（第20章起，2026-10-08 按正典节拍+可见度补丁整理）

### U12 丝线与冰霜·限制（第20章/节拍Ch10）— 事件单元：问答定名
- **小故事**：对练场上霜印接三轮、霜华反压半秒；收拳后陆沉问"为什么这么拼命"，他答："不拼尽全力，就没办法得到完全胜利。"
- **单元闭环**：白砚河没赢，但拿到可验证的收手目标；陆沉私人介入自此开始（F031④）。
- **暗线**：左臂实验后果→恢复曲线异常+旧训楼出入记录→方导师有依据限权——读者可见的"陆沉不对劲"第一帧。
- **抛出的钩**：完全胜利问答；"站在最前面的人"镜像。

### U13 加练期·无名分的师徒（第21章起/节拍Ch11-13）— 日常热血单元：培养与裂缝
- **小故事**：亲传规格加练——停住无效追击（Ch11验证）；他第一次替队友挡在前面（第二次训练事件）。
- **单元闭环**：输了对练，学会收手、确认队友位置——"努力有独立于输赢的成果"（F031⑤，为⑦答案拍量变积累）。
- **三帧补丁（2026-10-08已入正典）**：认师帧（白砚河POV"明天老时间"）、面具裂缝帧（"死者/回来"话题的一帧停顿）、四人桌旁观镜头（林见星察觉他不再死盯哥伦比娅）。
- **抛出的钩**：方导师限制升级（停带队与内部调查方向）。

### U14 同源核验与约谈（节拍Ch14-16）— 悬疑单元：证据链合拢
- **小故事**：苏弥物件同源核查落地（F020由隐转显的枢纽，不得丢拍）；走廊交锋；正式约谈；决裂前托付（F031⑥："站到最前面之前，先看一眼身后"方向）。
- **单元闭环**：证据逐层成立；她试图挽回，他确认对方能否追上。

### U15 卷末引爆（节拍Ch17-22）— 高潮单元：导师即BOSS
- **小故事**：撕封诱敌、导师战、学生救援、强制撤离；她刻意留下问"现在收手还来得及"；私谈交线索；浅层反面同归。
- **单元闭环**：复仇终点=林昭安息；女主留场获得线索、组织核实她与封印关联、误认始主代理人（第二卷引力）。
- **补丁帧**：揭晓点"回看装置"约半页蒙太奇（F019/F020/听拍第七圈/F027/"我来"）。

### U16 沉淀（节拍Ch23）— 收束单元：答案与墓前
- **小故事**：白砚河痛而不崩——"他的答案我记住，他的路我不走"（F031⑧）；墓前对话，林见星替那个笨蛋道谢。
- **单元闭环**：完胜定义第二层落棺——"没有人被落下"包括站在最前面的人自己。
