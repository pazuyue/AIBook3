# 第3章 新家的白灯

哥伦比娅在第七救助医院住了二十七天。

第一周，她渐渐认熟了来分餐的护士。

午餐车一在门外停下，对方便会从托盘里挑出加了糖的那份，放到她床边的小桌上。她不用开口，护士也记得。

医院夜里偶尔会做反面预警演练。第一次听见警报，她撑着床坐了起来，直到值班护士过来核对人数，告诉她只是演练，才慢慢松开攥住被角的手。

这些都是小事。

小到写进任何一份个人档案里，都占不了一行。她当然知道什么是配餐、医院和警报；可死过一次，又在另一具身体里、在那片灰白废墟中醒来之后，连"明天还会照常到来"，都成了一件需要反复确认的事。

于是，午餐车每天经过，演练结束后，走廊里又恢复了熟悉的脚步声。那些属于"生者世界"的琐碎日常，一点点把她从死亡留下的恍惚里拉回来。被子有温度，床垫承着身体的重量，她确实住在这个房间里，也确实还会在第二天早晨醒来。

闻澈每天都会来。

有时是早上，有时已经深夜。那件洗得发白的白大褂常沾着冷雨的腥味，袖口偶尔留着消毒水也洗不净的浅痕。来得早，他会带上医院食堂刚热好的豆乳和小面包；来得晚，就坐在床边的椅子上翻那本厚厚的灾后安置条例，等她把当天的药吃完。

他不问她从哪里来。

她听不懂别人随口提起的词，也认不出窗外那些常见的标志，他同样不追究，只挑眼下用得着的，一件件讲给她听。

"曜月城在学院城外圈，靠近几处监管反面，所以救助医院多。"

讲到学校的入学检测时，他提起一种叫月相仪的仪器。

"也是检查身体用的？"她问。

"是看一个人对神秘体系的适配情况。学校和神秘机构都有，学院安排训练时会参考检测结果。"

她记下这个名字，又翻回前面写着"以太"的那一页。

"神秘者的力量，都来自以太吗？"

"核心能力和术式都可以调用以太。你可以先把它理解成一种能量，不是能力本身。"闻澈说，"同样是神秘者，有人擅长治伤，有人擅长防护，也有人能做特殊的器具。"

"是学的东西不一样？"

"有这方面的原因。但每个人的神秘核心也不一样，决定了各自的能力。术式是可以共同学习的技术，核心不是。"

哥伦比娅想了想。

"也就是说，同样去上课，能学会相同的术式，但未必能做到对方用核心做的事。"

"对。术式能不能用好，也得看各自是否适合。"

她把原先写在一处的两个词分开，重新补上说明。窗外有人推着轮椅经过，轮子在地砖的接缝上颠了一下。

"医院里也有神秘者吗？"

"有，但不是人人都有治疗能力。这里也用药、用器械、做手术。"闻澈把她喝空的杯子拿过去，添了些水，"你这次低血糖，补糖就有效，没必要另外动用术式。"

她接回杯子，指腹贴着温热的玻璃。

"那反面的事，也是学院负责？"

"你被救出来的地方归学院监管。城里的事故有处置队负责，我们接手救回来的伤员和需要安置的人。学院会培养相关的人，也会派人参与处置，但不是所有事都归它管。"

她补完笔记，把本子放回床头。那些起初混在一起的陌生名词，终于能分出一些头绪。

住院的日子也渐渐有了规律。

早上量体温、吃饭，做恢复训练。午后去安置区的小教室，认识三月历、重新划分的城市地图，以及能与以太交互的公共终端。傍晚闻澈有空，就带她到楼下花园走一圈，指给她看那些受过轻微侵蚀、模样变了却依然无害的植物。

最初几次恢复训练，她总会等来一段多余的空白。

医官让她沿走廊的白线走十米。她走完，停在尽头，等着胸口那阵熟悉的刺痛追上来。

没有疼。

扶着栏杆上下楼梯时也是。她习惯在中途歇脚，等眩晕过去；这一次停下来，听见的却只有楼道里的脚步声。

也没有晕。

医官在表上勾完一项，示意她继续。她松开栏杆跟上去，过去那些不得不停下的地方，如今都能径直走过。

真正需要花时间习惯的，反倒是从前没留意过的小事。转身时，长发总要慢半拍才扫过肩背；夜里翻身压住发尾，头皮被扯得疼了，她才想起先把头发拨开。

过了几天，她记得在清晨起身前捞出颈后的长发，喝水时也会先按住滑到胸前的那几缕。在走廊里迎面遇见推车的人，对方常会收慢脚步，替她让出一条路，等她走过去才继续往前。

她仍会觉得别扭，只是不必再为每一件小事停下来想很久。那具从月光里接过来的身体，渐渐有了属于她自己的日常。

她开始能分清医院和学院的徽记。也知道了方芷凝导师是第三区事故现场的带队人，负责跟进她那份事故档案。

但方导师极少出现。

她只在走廊尽头见过那位气质冷淡的女导师两次。对方没有盘问她，也没有把她当成需要戒备的嫌疑人，只是在听取医官汇报时，远远地向这边投来一眼。

那一眼并未做多余的停留。

哥伦比娅记住了那一眼。普通的安置登记做完了，那位导师跟进的档案却还没有结束。

她低下头，笔尖落回便签上，却没写出下一个字。

不能让别人知道。

这个念头一直没有松开。姓名、住址，还能说是记不起来；可在这具身体里偶尔发生的事，连她自己也找不到解释。她明明只想做一件寻常的小事，伸出的手却未必会给出寻常的结果。

第一次出现端倪，是在病房里。

半夜醒来，她觉得口渴，伸手去拿床头柜上的玻璃杯。指尖刚碰到杯壁，水面便停住了。

杯子被她带得轻轻一倾，水却没有随之流向较低的一侧。

水面仍与杯口平行，连倾斜的角度都分毫不差，像一片嵌在杯中的透明薄片。窗外的淡光映在上面，没有散开。她停住手，指尖贴着杯壁，一时不敢再动。

她看了三秒，将杯子放回原处，慢慢松开手指。

水面这才晃开，细细的涟漪碰上杯壁，又一圈圈退回来。

第二天早上，闻澈拿起那个玻璃杯。杯壁上留着一圈很淡的白痕，摸上去的温度，比周围的空气还要凉上几分。

哥伦比娅坐在床上，手指微微压着被角，没有说话。

闻澈也没有追问。

隔天，他带来一只厚瓷杯，将玻璃杯换了下来。瓷壁不透光，握进手里沉沉的。

"厚瓷杯不容易凉。"

他说得随意，顺手替她倒好水。窗外还是夏末的闷热，病房里的风扇正缓缓转着。

哥伦比娅接过杯子。手指贴着温热的瓷壁，过了一会儿，才轻声说："谢谢。"

闻澈将那只留着白痕的玻璃杯放进柜子深处，合上柜门。杯子被收了起来，那一圈白痕也没有再被提起。

第二十八天，灾后安置处下发了临时监护手续。

闻澈带她去了一间不大的办公室。工作人员核对她的恢复情况，请她读过表上的文字，又问了她自己的意愿，才将一份盖着钢印的临时监护书推到面前。

"你可以继续住院观察，也可以去安置家庭。闻澈医官已经交了申请，不过，要你自己同意才会生效。"

工作人员说得很慢，手指停在尚未签字的空栏旁。

"不愿意也没关系，你可以拒绝。"

哥伦比娅偏过头，看向坐在身旁的闻澈。

闻澈双手放在膝上，坐得很直。她看过去时，他像是想说什么，最后只是朝她点了点头。

那件白大褂的袖口还挂着早上出急诊时勾出的线头。他用拇指捻住线头，又放开，始终没有替她回答。平时在病房里能一坐半夜的人，此刻却连椅背也没靠。

哥伦比娅收回目光。文件还带着新印的油墨味，钢印在纸边压出细小的凹凸。

监护人：闻澈。

被监护人：哥伦比娅·希珀塞莱尼娅。

关系类型：灾害失依未成年人临时收养观察。

她读完这三行字，拿起桌上的签字笔，在空栏里写下自己的名字。

签完，她将文件推回工作人员面前，看了一眼身旁的闻澈。这一次，手续办完以后，会有人和她一起离开。

闻澈带她回家的那天，曜月城下了一场带着凉意的小雨。

出了医院，在第一个路口，她认出了小教室地图上的街名。闻澈撑着伞，带她沿那条街往前走。

街角的面包店开着半扇门，烘烤的甜香混进潮湿的空气。有人把伞夹在臂弯里，腾出手接找零；公交站前挤着几名穿校服的学生，正争论放学后该先去哪一家店。送货的人推着小车经过，轮子陷进积水，低声抱怨了一句路面。

站牌旁立着一台公共终端。有人按开路线图，指示纹沿着屏幕边缘亮起——她在安置区的小教室里见过，这是带有以太交互功能的设备。问路的人找好方向，撑开伞便走了。

几步之外，雨棚立柱上钉着反面预警牌，下方标出了最近的避难路线。卖面包的人把价目牌挂在旁边，伸手抹掉上面的雨水。

哥伦比娅从预警牌看到那块写着今日价格的小黑板，又看向玻璃后排得整齐的面包。

闻澈把伞往她那边挪了挪。

"前面拐弯就到了。"

她收回视线，跟上他的脚步。

他的住所位于医院和处置队驻地之间，是一栋上了年头的旧公寓。楼下的便利店二十四小时亮着灯，玻璃门上贴着褪色的反面预警说明。电梯升得很慢，金属摩擦声从轿厢外细细传来，听得人牙根发酸。

房子并不宽敞。

客厅靠窗摆着一盏白色落地灯，灯罩边缘贴着一截修补用的胶带。餐桌上放好了两套餐具，一大一小。冰箱门上，一枚磁贴压着字迹潦草的备忘清单：

牛奶。

鸡蛋。

儿童拖鞋。

发绳。

她站在玄关，鞋尖抵着闻澈那双旧拖鞋的边沿，目光还停在冰箱上的清单上。

闻澈收好滴水的雨伞，放进门外的伞架，弯腰将一双新拖鞋摆到她脚边。小小的，尺码正合适。

"左边是你的房间。床单早上刚换过。"

她看向左边那扇门，仍旧站在门垫上。

闻澈没有催，将门禁卡和一串挂着浅蓝色扣环的钥匙放进玄关的小瓷碗。金属碰到瓷沿，叮地响了一声。

"这张卡开楼下的门，这把钥匙开家里的门。"

他把钥匙往她那边推近了些。

"回家用的。"

哥伦比娅低下头，注视着那把静静躺在瓷碗里的钥匙。

她捻住浅蓝色的扣环，将钥匙拿起来。扣环背面用黑色记号笔写着她的名字，一笔一画，都很工整。

钥匙很轻。

拢进掌心，齿口微微硌着皮肤。她低头换上那双小拖鞋，脚底贴到柔软的布面，却舍不得把钥匙放回碗里。

闻澈经过客厅，按亮那盏白色落地灯，才转进厨房。

暖光铺过玄关的瓷碗、餐桌上的两套餐具，落在冰箱门的清单上。灯罩边缘的胶带映出一道浅影，左边那扇房门也被照亮了。

一双合脚的鞋，一把写着她名字的钥匙，还有这盏修补过的灯。在她走进这扇门以前，屋里就已经给她留好了位置。

"进来吧，哥伦比娅。"

他的声音从厨房里传出，伴随着水流冲刷蔬菜的轻响。

"饭快好了。"
